# Reference yardstick (NOT the submitted code)
Before Arc Studio was available, a spec + reference contract and a 26-test Foundry suite were drafted locally.
They were used only to check Arc Studio's output; the submitted contract is `contracts/VerifyPayEscrow.sol`, generated by Arc Studio.

- `src/VerifyPayEscrow.reference.sol`: the local reference implementation (kept for the diff in `../diff-reference-vs-arcstudio.diff`).
- `test/`: the independent 26-test suite (+ an Arc fork test on real USDC). It was run against Arc Studio's contract
  (results in `../test-logs/`): v01 failed to compile (no constructor arg) → prompt 02b; final: 26/26 after raising two
  fuzz bounds to ≥60 s to match Arc Studio's new `MIN_DEADLINE_SECS = 60`.

To re-run: copy `contracts/VerifyPayEscrow.sol` to `src/VerifyPayEscrow.sol` in a Foundry project with these tests
(remappings: `@openzeppelin/contracts/`, `forge-std/`) and run `forge test`.
