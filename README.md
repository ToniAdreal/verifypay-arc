# VerifyPay: pay AI coding agents only on a verified PASS (Arc + USDC)

**Built in [Arc Studio](https://studio.arc.io).** The contract, its tests and the web app in this repo were generated and iterated by Arc Studio from the prompts in [`arc-studio/prompts/`](arc-studio/prompts/); see [docs/ARC_STUDIO_RUN.md](docs/ARC_STUDIO_RUN.md) for exactly how.

**Live app (Arc mainnet, read-only without a wallet):** <https://toniadreal.github.io/verifypay-arc/?net=arcMainnet&contract=0x3622FfDCFE88c542aB1203a00282e128159edDE7>

VerifyPay is a USDC escrow on [Arc](https://docs.arc.io). A payer locks USDC for an AI coding agent. The money moves only when a
**designated verifier signs an EIP-712 `PASS`** over `(escrowId, deliverableHash)`. If no PASS arrives before the deadline, the payer refunds.
Anyone can relay the PASS (the agent itself, the payer, or a bot), so nobody has to click "pay".

The deliverable hash can be the `record_hash` of a [VerifyGate](https://github.com/ToniAdreal/verifygate) evidence record: VerifyGate runs
deterministic checks on an agent's code change and issues a hash-chained evidence record; VerifyPay turns a PASS record into an on-chain payment.

```
 payer ──approve + createEscrow(payee, verifier, amount, deadline, specHash)──▶ VerifyPayEscrow (holds USDC)
 agent ──delivers work──▶ verifier runs checks (e.g. VerifyGate) ──PASS?──▶ signs EIP-712 Pass(escrowId, deliverableHash)
 anyone ──release(escrowId, deliverableHash, sig)──▶ contract checks signer == escrow.verifier ──▶ USDC → agent
 no PASS by the deadline: payer ──refund(escrowId)──▶ USDC → payer
```

## Contract (`contracts/VerifyPayEscrow.sol`, generated by Arc Studio)
- `createEscrow(payee, verifier, amount, deadline, workSpecHash) → escrowId`: pulls USDC via `transferFrom` (approve first); deadline must be ≥ 60 s ahead.
- `release(escrowId, deliverableHash, signature)`: anyone can call; the signature must come from the escrow's verifier over EIP-712 domain
  `{name:"VerifyPay", version:"1", chainId, verifyingContract}` and type `Pass(uint256 escrowId,bytes32 deliverableHash)`. EOA and ERC-1271 verifiers.
- `refund(escrowId)`: payer only, after the deadline. Each escrow settles once: `Open → Released | Refunded`.
- OpenZeppelin 5.1: SafeERC20, ReentrancyGuard, EIP712, SignatureChecker. USDC only through the ERC-20 interface (6 decimals), never `msg.value`.
- Security review by Arc Studio: [docs/security-review.md](docs/security-review.md). Arc network facts with sources: [docs/ARC_FACTS.md](docs/ARC_FACTS.md).

## Run it
```bash
# Web app + contracts (Arc Studio project layout; needs bun and Foundry)
bun install
bun run contracts:test      # forge test
bun run dev                 # http://localhost:5173  (?net=arcMainnet or ?net=arcTestnet, &contract=0x… to override)

# Box-side scripts (ethers): deploy and the end-to-end demo
cd tools && npm install
cp .wallet.env.example .wallet.env && chmod 600 .wallet.env   # throwaway keys only
node scripts/balances.mjs --network testnet
node scripts/deploy.mjs --network testnet
node scripts/demo.mjs   --network testnet --refund-ttl 70 --sweep-back
# Mainnet needs --i-understand-this-is-mainnet; the demo is hard-capped at 2 USDC per escrow.
```
The app connects any injected EIP-1193 wallet, switches/adds Arc, and has payer, verifier (paste a VerifyGate evidence JSON, sign with
`eth_signTypedData_v4`) and release/refund panels, plus an escrow table. Fees use `max(2·baseFee, 20 gwei) + 1 gwei` (Arc's mempool floor is 20 gwei).

## Hosting (GitHub Pages)
The live app is Arc Studio's app, unchanged, built with Vite's base path set on the command line and published to the `gh-pages` branch:
```bash
bunx vite build --base=/verifypay-arc/    # no source or config edits
# publish dist/ (plus an empty .nojekyll) to the gh-pages branch
```
With no URL parameters the app opens on Arc testnet (Arc Studio's default), so the live link passes `?net=arcMainnet&contract=0x3622…dDE7`.
The build contains no keys or API tokens (gitleaks scan of `dist/`: no leaks). It reads chain data straight from the public Arc RPC (`https://rpc.mainnet.arc.io`, which allows CORS from `toniadreal.github.io`).
